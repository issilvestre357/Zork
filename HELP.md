# Zork Help

## Commands

### Movement
- `north`
- `south`
- `east`
- `west`
- `move`
- `move on`

### Looking Around
- `look`
- `see`

### Pick Up Items
Examples:
- `pick up fuse`
- `grab fuse`
- `take fuse`

If you do not name an item, the game will ask which item you want.

### Drop Items
Examples:
- `drop fuse`
- `leave fuse`

### Inventory
- `inventory`

### Game Controls
- `restart`
- `quit`

## Goal

Escape the pizzeria.

## Hint

You will need the Tool Belt before carrying most other items. Restoring power in the Supply Closet will help you find something important in the Kitchen.
